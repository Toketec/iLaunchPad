# 冲刺 1：基础原生 Launchpad

## 目标与交付边界

完成基础原生启动台的浏览、启动、分类和整理闭环；保持现代 macOS 原生质感，并支持从兼容 LaunchOS 布局及 macOS 26 以前系统 Launchpad 数据迁移布局。不是仅补迁移文档，也不是按 bug 数量建立规格。

功能编号和归属以 [细功能清单](functional-overview.md) 为准。本页只定义业务规则；实现事实、差距、测试和用户确认分别归所属规格 tasks/check。7 个功能板块划分已获用户确认；文档补齐不等于缺失功能的实现方案已获评审。

## R1 应用与布局（DATA）

- 已有有效 iLaunchPad 布局优先。刷新、安装新应用、重新打开不得打乱既有顺序。
- 安装目录变化自动触发后台核对；新应用追加到最靠近首页且不足35格的页面末尾，全部满才新建页；拖拽中延后合并。
- 页面、顶层位置、单层文件夹、组内位置分别保留；App 身份不能等同可变化的格子或文件夹身份。
- 两类导入来源是独立入口：LaunchOS；旧系统 Launchpad。后者既包括仍可读取的本机遗留数据，也包括用户选择的备份。不能要求旧软件/旧系统还能够运行。
- 主动导入是替换布局，不是把两个来源随意混合。确认前说明来源与覆盖影响；取消不变更。解析与校验成功后才替换，并应保留恢复副本。
- 优先用稳定应用标识匹配本机 App，路径作为定位信息；缺失应用、重复身份、空组、无效条目应有明确结果说明。不凭同名把不同 App 合并。
- 没有旧数据时只可建立新布局，不声称能推算原排序。旧系统格式/备份完整性未确认时，应拒绝或明确不支持，不尝试修改系统数据库。
- 初次无自身布局时，现有 LaunchOS 兼容数据库可自动只读迁移；旧系统来源实现后若发现多个可用来源，应让用户明确选择。当前实际启动链路的差距见 spec-001。
- 自动发现、手动刷新、外部卸载后的失效处理须分别验收。不能用“刷新能发现”替代“安装后自动出现”。
- 事务提交、保存失败、损坏布局保留和恢复都是功能的一部分，不以文件写入调用存在代表已可靠恢复。

## R2 唤起与返回（SHELL）

- 启动、再次点击 App、声明支持的快捷键能够唤起；显示器由鼠标所在屏决定。
- 进入启动台时隐藏 Dock，正常离开时恢复之前的显示策略，不永久改系统 Dock 配置。
- 点击普通应用/回车激活会收起启动台；切换到已有其他应用同样收起。单纯方向键选择不关闭。
- Esc 优先级：取消当前拖拽 → 退出编辑 → 关闭文件夹 → 清空搜索 → 关闭启动台。没有拖拽时点空白遵循相同的后四层优先级。
- 再次打开清空短期交互状态；只保留已提交布局和偏好指定的页面。
- 起始页未配置时打开首页；用户显式关闭“每次打开时回到第一页”后继续记忆上次页，不覆盖其选择。
- 默认首页在窗口展示前无动画复位，再以首次打开相同的spread效果展开；不把打开操作表现为从上次页横向翻回首页。
- 外部拖到 Dock 属于原生基础对照目标。不能将“拖出本窗口=无效落点撤销”的内部拖拽规则直接套到 Dock 导出；需要先明确受支持的外部接收和 Dock 显示时机。
- 全局手势、热角和更深系统集成见细功能清单 D1，不宣称本地缩放关闭等于全局捏合唤起。

- 可选登录启动使用 macOS 登录项机制，由用户主动开启；默认不自动注册。登录进入后台待命，不弹出全屏、不抢焦点、不隐藏 Dock；手动启动/再次打开仍正常展示。关闭开关不影响本次使用，用户退出后不被守护进程再次拉起。

## R3 浏览、搜索和启动（FIND）

- 主页展示保存顺序；分页整体横向移动，裁剪发生在屏幕边缘，不是网格两侧。一个物理滑动只作一次落页决定，快速反向可中断前次动画。
- 点击页点、Command-左右、滚轮、触控板和方向键导航分别有自己的输入规则；触控板惯性不能触发第二次分页。
- 搜索覆盖全部非隐藏 App（包括组内），不改位置；有结果时默认第一项，空结果不可激活。查询完全相同优先，其后前缀、包含、拼音/首字母、Bundle ID。
- 搜索、展开组、拖拽时主页普通翻页停用；搜索结果不支持拖拽重排。大量结果仍需能访问。
- 输入法组词未结束不截获确认键；编辑文字时左右键用于光标。搜索栏只呈现一个搜索图标，清空后回到原页面。
- 点击 App 和回车、组内和组外、右键打开必须遵循一致的启动/关闭规则。找不到 App 或启动失败要有可感知反馈，不能误操作别的应用。
- 键盘选中不是启动；编辑态单击/回车不启动。

- 缓存加速自动工作，无需用户管理。命中内存或磁盘资源后优先准备当前页；应用更新、同路径壁纸变化、缩放或屏幕变化需正确失效。缓存缺失/损坏/空间不足时正常回退，不能丢失应用排序。后台扫描结果只补入当前布局，不覆盖期间完成的整理，拖拽中延后合并。

## R4 文件夹（FOLDER）

- 单层文件夹；两个普通 App 重叠停留达阈值后生成并展开临时组，初始顺序为目标 App、拖动 App；按住时可以继续换位。组内松手才保留组并聚焦默认名称，供立即改名。不把整个文件夹嵌入另一文件夹。
- 展开/收起从实际组图标位置连续衔接；组外是磨玻璃模糊。展开后屏蔽下方主页点击，不把动画中的模型坐标当成可点图标。
- 组内支持浏览、启动、编辑、换位和移出；过多成员必须可访问，导航形式见 D2。
- 名称输入保留输入法行为，提交或失焦保存；名称全空白的默认名为“未命名”。完全清空输入的具体提交行为须与此规则一致。
- 组成员减少到一个时自动解散，剩余 App 在原组位置成为普通 App；零成员移除。拖拽中这是可撤销预览，原容器身份保存在快照，不必为取消而留一个可见空壳。同组内部换位的中间 remove/insert 不触发解散，只有完整移动操作结束后的成员数参与判断。拖出、菜单移出、卸载统一规则；隐藏不减少成员数。
- 缩略图、名字、玻璃材质、尺寸和圆角定义在原型，不在每个规格重新定一套视觉参数。

## R5 连续拖拽（DRAG）

一次从按下起拖到松手/取消的过程是**一个操作**。跨组、跨页不结束它。

| 阶段 | 判断与动作 | 不允许的行为 |
|:---|:---|:---|
| 起拖 | 保存起始布局，绑定稳定 App 身份 | 用会消失的旧格子索引代替身份 |
| 经过格子 | 根据当前位置和短暂停留换位 | 一经过外围就把目标组推走 |
| 位于组图标 | 先整体放大选中，再停留展开；快速合法松手可直接加入 | 画外框、放大命中区、选中后锁死换位 |
| 位于普通 App 图标 | 中心重叠稳定停留达合组阈值 → 在目标位置创建并展开临时组 | 先换位导致目标逃走；仅标记合组却一直等松手 |
| 走向展开面板 | 留出接近与容差范围 | 尚未进入就误收起组 |
| 组内移动 | 实时换位，只改变内存预览 | 新建第二份可见 App 或第二份模型记录 |
| 退离组 | 收起并返回外部预览；继续监听 | 提前提交、断掉手势、无法重新打开组 |
| 退出临时组 | 解散临时组，恢复合组前目标 App 的身份和位置，继续拖动 | 还原整次拖拽导致此前换位全丢；留下单成员临时组 |
| 到屏幕边缘 | 停留切页后继续操作 | 普通翻页与拖动翻页同时处理 |
| 最终松手 | 按当前几何落点提交一次，停留时长不影响合法性 | 使用旧落点、真实接收事件丢失后回弹 |
| Esc/关闭/无效落点 | 恢复整个操作起始布局并结束监听 | 仅恢复最后一步，留下半次操作 |

鼠标携带的图像与网格占位分别管理：跨容器期间保留占位和命中，只抑制重复的网格内容；结束恢复。组本身和其他 App 不能被隐藏。取消和成功提交都清理监听、悬停反馈与延迟事件。

现有意图阈值及接收路径由 spec-005 维护；满页/末页新增页的目标行为见 D4，不能用当前已有页之间可拖动代替这一项。

临时合组是整体拖拽中的局部预览，不是提前提交。拖出临时组仅撤销这次合组，保留此前的预览排序；Esc/失焦/关闭则撤销整次拖拽。拖出后可再次停留合组，或进入已有组、切页、与外部 App 换位，直到最终松手。

中心未达到合组阈值就离开或松手，不创建新组；普通排序按最终位置处理。已有组上的快速松手加入规则不变。新组只有在自身面板内有效松手才进入命名；仍按住时不抢名称输入焦点。命名回车或失焦保存；放弃输入保留默认名，不撤销已经成立的组。

## R6 编辑与应用管理（EDIT）

- 长按进入编辑并抖动；不要求先松手才允许拖动。完成、空白、Esc 可退出。
- “隐藏”“移出文件夹”“卸载”是三个不同动作。隐藏不删除文件，移出不卸载；所有允许卸载的应用统一二次确认后移入废纸篓。
- 系统目录/Cryptex系统组件、Safari等必需应用、自身、嵌套helper及重定向路径不显示卸载按钮。不因com.apple.*前缀一律禁止Apple独立应用。二次确认后重新验证身份、位置和文件可删除性；运行中的目标先退出。
- 确认框明确只移动当前 `.app` 应用包，不清理个人文稿、设置、缓存、共享容器或辅助文件，也不取消订阅；取消不改变文件或布局。
- 废纸篓操作成功才清布局并执行统一的文件夹收尾；取消、权限变化、应用仍运行或移动失败均保留布局并反馈。
- 编辑抖动时，图标、名称、文件夹材质和卸载叉号保持同一相位和位移，叉号不悬停在静止位置。
- 不提权强制删除，不启动外部卸载器或脚本，不调用私有卸载 API，不承诺清除应用残留。

## R7 偏好（PREF）

设置使用原生组件。图标大小、名称、壁纸模糊、起始页选择立即反映且重启保留。偏好对组内/组外的作用范围需要明确，不把一个开关展示为全局却只实现一半。减少动态效果遵循系统，不能让动画完成后的状态收尾消失。

本冲刺在历史里程碑使用用户确认的白底石墨火箭作为可构建初始图标，并拥有图标选择、即时应用、偏好保存、重启恢复与缺失回退的运行时行为。当前四款玻璃主题的视觉设计、原稿、配色、发布封装与目录生产归冲刺 2 spec-001；访达使用当前发布包的默认玻璃蓝图标。

登录启动开关读取系统实际状态，不用一个独立布尔偏好冒充注册成功。需要用户批准时提供系统设置入口；操作期间防止重复提交，失败说明原因并恢复真实状态。应用从后台返回时重新读取状态。

## 不属于本次文档整理的动作

不实现缺口、不恢复/读取用户真实布局、不卸载应用、不修改系统设置、不重建安装包、不更新技能或模板。缺口仍归上述 7 个规格；之后补代码先评审具体方案，不能再按单个 bug 拆新规格。
