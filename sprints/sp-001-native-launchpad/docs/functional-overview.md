# 冲刺 1：细功能清单

本文件是细功能编号和归属的唯一入口。规则见 [SPRINT-features.md](SPRINT-features.md)，场景见 [user-scenarios.md](user-scenarios.md)，实现与验收状态只在各规格 tasks/check 中维护。

## 1. 应用目录、布局保存与导入

| ID | 细功能 | 输入 → 用户可见结果及边界 | 范围 |
|:---|:---|:---|:---|
| DATA-01 | 应用发现 | 首次打开 → 汇总系统与用户安装的应用；不展示应用包内 helper | 基础 |
| DATA-02 | 身份与去重 | 多个来源中的同一应用 → 唯一身份，不因组/页变化复制 App | 基础 |
| DATA-03 | 本机布局优先 | 已有有效自身布局 → 读取原位置和文件夹，不被导入源覆盖 | 基础 |
| DATA-04 | 新增应用补入 | 监听安装目录变化自动补入；追加至最靠近首页且未满35格的页面末尾，所有页满才新增页；不打乱已有排序 | 基础 |
| DATA-05 | 主动刷新 | 刷新 → 补充新应用并刷新图标缓存；失败不清空现有布局 | 增强 |
| DATA-06 | 外部移除与失效项 | 应用外部卸载/移动 → 不误启动其他 App；无法匹配时反馈，自动清理策略需明确 | 基础 |
| DATA-07 | 布局持久化 | 整理、命名、隐藏 → 重启保留；保存失败有反馈 | 基础 |
| DATA-08 | LaunchOS 布局导入 | 首次无自身布局时自动只读迁移，或由用户主动恢复 → 保留页序、顶层顺序、组名、组内顺序及适用隐藏信息 | 增强 |
| DATA-09 | 旧系统 Launchpad 导入 | 读取 macOS 26 以前系统 Launchpad 的本机遗留数据或用户备份 → 恢复页序、文件夹和应用位置 | 增强 |
| DATA-10 | 来源选择与只读 | 选择来源/备份 → 只读读取；缺失、版本不支持、关联备份不完整时说明原因 | 增强 |
| DATA-11 | 应用匹配与结果 | 来源应用匹配本机应用 → 不因路径变化丢掉位置；说明无法匹配项及处理规则 | 增强 |
| DATA-12 | 覆盖确认与保护 | 主动导入 → 确认替换、保留可恢复副本；取消/读取失败不改原布局 | 增强 |
| DATA-13 | 无可用布局 | 无自身布局和可读来源 → 用本机应用建立初始布局，不伪称恢复成功 | 基础 |
| DATA-14 | 布局异常与恢复 | 损坏/格式不支持/写失败 → 保留可恢复数据并报错，不静默覆盖唯一坏文件 | 基础 |

## 原生对照与待决定边界

[Apple 的 macOS Sequoia 15 Launchpad 说明](https://support.apple.com/guide/mac-help/open-apps-with-launchpad-mh35840/15.0/mac/15.0)用于核对基础操作类别：打开/关闭、查找/启动、页面及键盘导航、整理文件夹、应用增删和拖至 Dock。不把旧版视觉带回本产品，也不据此承诺系统深度集成等同内建程序。

| 决策 | 归属 | 需要明确的选择 |
|:---|:---|:---|
| D1 系统集成范围 | SHELL | 全局捏合/热角、Screen Time、游戏控制器是否纳入；不自动扩展 |
| D2 大文件夹 | FOLDER-07 | 原版式横向分页或保留可访问全部成员的纵向滚动 |
| D4 页容量 | DRAG-13 | 满页自动顺移还是插入当前页，末页停留新建页时机 |

DATA-09 是用户明确要求，不是待定功能；其数据库版本、样本与解析方案由 spec-001 调研，不能把缺少样本写成已有支持。

单成员组规则已明确：成员减少到一个自动解散，适用于临时组和已有组的拖出、菜单移出、卸载；按整个拖拽取消时，恢复原快照中的组。不是仅为临时组增加特例。
