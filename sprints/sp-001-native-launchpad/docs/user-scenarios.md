# 冲刺 1：用户场景与验收路径

功能编号见 [细功能清单](functional-overview.md)。下表描述目标场景，不表示已经运行或通过；执行结果归所属 spec/check。

| 场景 | 前提和操作 | 期望结果 | 功能覆盖 |
|:---|:---|:---|:---|
| U01 日常启动 | 已有布局；唤起→切页→点击 App | 正确启动、启动台关闭、Dock 恢复；下次页码符合偏好 | SHELL-01～07、FIND-01～05/11、PREF-05 |
| U02 搜索定位 | 中/英文、拼音、首字母、无结果、大量结果；输入法组词、清空、回车 | 输入不被抢占；搜索含组内非隐藏 App；不改变排序 | FIND-06～14 |
| U03 文件夹使用 | 点击/回车展开→改名→选择成员启动；另一次点外部/Esc 关闭 | 来源位置连续动画、背景模糊、名称保存、操作对象正确 | FOLDER-02～07/09 |
| U04 同页整理 | 普通 App 换位；App 与组互换；组与组互换；普通 App 中心/外围经过和停留 | 意图区分明确，无蓝线；中心候选不被提前换位打断 | DRAG-01～05/14/17/18、FOLDER-01 |
| U05 连续进出组 | 组外起拖→悬停展开→走入组→组内换位→拖出→组外换位→再进入→停留 2 秒松手 | 一次手势不中断；无第二份图标；最终位置保留 | DRAG-06～11/14/16/17 |
| U06 直接组内起拖 | 打开组后起拖→组内换位或拖到另一组/主页→松手 | 原正常路径不被组外起拖修复破坏 | DRAG-01/09～11/14 |
| U07 跨页与新页 | 起拖→边缘停留→已有页换位→到末页外侧/满页 | 监听不中断，按确认的新页/容量规则处理 | DRAG-12/13 |
| U08 中途取消 | 在换位、组内、跨页等不同阶段 Esc/失焦/关闭/无效落点 | 全部恢复到起拖前；再次拖动不受旧事件影响 | DRAG-15～17、SHELL-05/07 |
| U09 长按编辑 | 按住 App 不放→进入抖动→继续拖动；再用完成/Esc/空白退出 | 不误启动；可移除项显示叉号；退出恢复 | EDIT-01～04 |
| U10 安全移除 | 可删除样本点叉→取消；再确认；确认前改变权限/位置或保持运行 | 取消不改动；成功只进废纸篓；异常拒绝且明确提示 | EDIT-04～07 |
| U11 非破坏管理 | 隐藏 App→搜索→显示全部；组内右键移出；访达定位 | 隐藏不同于卸载，恢复可见，移出后容器规则一致 | EDIT-08～10、FIND-14、FOLDER-08 |
| U12 LaunchOS 继承 | 使用隔离源，含多页、多组、隐藏项、重复/缺失应用；首次无自身布局自动迁移；另测主动恢复的确认和取消 | 页/组顺序恢复，取消不覆盖，源库不修改 | DATA-08/10～12 |
| U13 旧系统布局继承 | macOS 26 以前 Launchpad 本机遗留数据或备份；同时有 LaunchOS；源缺失/不兼容/备份不完整 | 可明确选来源；支持的样本恢复页序、组名和组内顺序；失败保留原布局，不伪称恢复成功 | DATA-09～12 |
| U14 新应用与故障恢复 | 新安装/外部卸载；无数据启动；损坏自身布局；保存失败 | 可发现新增应用，失效项不误开；数据可恢复，不静默覆盖 | DATA-01～07/13/14 |
| U15 设置和多屏 | 改大小/名称/模糊/起始页；换屏唤起；减少动态效果 | 设置作用范围明确且持久，命中不漂移，功能不依赖动画存在 | PREF-01～07、SHELL-03 |
| U16 添加至 Dock | 从启动台向 Dock 拖动有效 App | Dock 能接收，启动台仍保留该 App，Dock 显示策略恢复 | SHELL-09 |
| U17 快速反复输入 | 连续翻页反向、开组收组、动画中点图标、在文本框/确认框操作 | 不错层、不误启动；旧回调不盖过新操作，输入归当前控件 | FIND-02/13、FOLDER-03/04、SHELL-05 |
| U18 临时建组确认 | A 在 B 中心稳定停留达阈值，不松手；自动展开后组内多次换位，再松手 | 两项临时组展开，图像唯一；最终组保留、顺序保存、名称自动聚焦 | DRAG-18～20/22、FOLDER-01/10 |
| U19 临时建组撤回 | 先在外部换位，再临时合组，按住拖出；再次悬停同一/另一 App 合组或跨页松手 | 临时组消失、目标身份位置恢复，之前预览换位保留；持续拖动正常，外部松手不弹命名 | DRAG-21/11/12/14 |
| U20 合组取消 | 临时组展开中、组内换位后、拖出后分别 Esc/失焦/关闭 | 整体起拖快照完全恢复，不遗留临时组、监听、隐藏图标或延迟命名 | DRAG-15～17/19～22 |
| U21 单成员解散 | 从两项已有组拖出一项；另测菜单移出/卸载；同组内换位作对照 | 成员减少到一项时解散且剩余项留在原组位置；同组换位不误解散；拖拽取消恢复原组 | FOLDER-08、EDIT-07/10 |

U05 必须同时测“立即放手”和“停留后放手”，不能只测一种。U05/U06/U08 分别覆盖组外起拖、组内起拖和取消；任何一个通过不替代其他路径。

新导入、数据损坏和卸载测试只用隔离目录/样本。验证用户已存在的真实布局前先备份，未经授权不执行覆盖或真实卸载。
