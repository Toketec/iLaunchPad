# 原生启动台界面基线

本项目已有运行中的原生界面，下列尺寸以 apps/ilaunchpad/Sources/iLaunchPad/ 为当前基线，业务目标以细功能清单和 SPRINT-features.md 为准。本次文档整理不生成 HTML 仿制原型；HTML 无法验证系统玻璃、原生拖拽或输入事件。新增导入等界面要求不等于已有代码。

## 全屏与搜索

全屏无边框窗口覆盖当前鼠标所在显示器。顶部居中胶囊搜索，左侧一个放大镜、中间原生搜索输入、右侧更多菜单，避免重复图标和占位重叠。页面底部居中玻璃页点，编辑模式右上“完成”。

普通网格 7 列、5 行，宽 min(1480, 屏幕宽×0.84)，上留白 max(108, 高×0.115)，下留白 max(120, 高×0.12)，图标尺寸按 GridMetrics 与设置计算。整个页面按屏幕宽度移动，网格留白跟随移动，裁剪只在屏幕边缘。搜索结果复用网格但不允许重排；无结果显示放大镜与“没有找到应用”。

## 文件夹

面板宽 min(1120, 屏幕宽×0.80)，中心在屏幕高约 47%；高度 min(屏幕高×0.65, 行数×168+48)。内容横向内边距 40、纵向 24；7 列、图标目标尺寸 100，受单元空间约束；行数由应用数向上取整。面板与内容使用 44 连续圆角。名称位于面板上方；背景用 within-window 磨玻璃。展开时搜索与页点隐去。

组图标使用常规图标尺寸的 82%，九宫格预览，圆角半径为组尺寸×0.235。命中区域不随选中放大扩张。拖拽选中整体放大 1.14，无额外外框。面板从组图标位置变换到最终尺寸，过渡期间不触发内部 App。

## 编辑与确认

长按 550ms 进入编辑；应用图标、名称与圆形叉号作为一个视觉整体轻微同步抖动，符合资格的 App 显示叉号。确认框先提供取消，再提供移到废纸篓；提示只删除应用包，不删除个人文稿、设置、缓存和辅助文件，也不取消订阅。减少动态效果时抑制抖动并缩短过渡。

视觉偏好见全局 visual-design.md；重复图标、跟手性和视觉质量是否通过由规格 check.md 记录，不以此文档替代实机评审。

## 来源导入界面要求（DATA-08～12）

入口应分别明确“LaunchOS 布局”和“旧版 macOS Launchpad 布局”，后者支持选择本机遗留数据或备份。不得把旧系统导入藏在 LaunchOS 标签下。当前只有 LaunchOS 菜单动作，新增控件的实现由 spec-001 承担。

一次导入需要呈现：来源名称与位置、可读取/缺失/不支持/备份不完整的结果、可恢复页面/文件夹/应用的概况、无法匹配项，以及覆盖当前排序的确认。取消保持当前布局；错误提示不与“恢复成功”共用状态。确认后应能找到覆盖前的恢复副本。具体控件采用系统文件选择与确认组件，不另做复杂管理台。

## 临时合组与命名界面

普通 App 中心重叠停留达到阈值后，从目标 App 当前图标位置生成并展开临时组，沿用已有玻璃面板、圆角和内部网格。按住期间名称只展示默认值、不抢焦点，拖拽影像/占位遵循既有唯一显示规则。拖出后临时组收回并还原为目标 App；留组松手后保持展开，名称获得原生输入焦点并选中默认文本。回车/失焦保存；未输入则保留默认名。加入已有组不触发自动命名。此节是目标交互，具体实现由 spec-004/005 承担。

## 登录启动设置（PREF-08）

在现有原生设置的交互区域增加“登录时启动”开关，说明“登录后在后台待命，不自动打开启动台”。系统未注册时默认关闭；已注册时反映实际状态，不重复注册。需要批准时显示“需要在系统设置中允许”及“打开登录项设置”按钮，失败信息在当前区域呈现，不假装已开启。应用从后台返回时重新读取状态。缓存自动运行，本轮不增加缓存管理面板。

## 入口与输入关系

| 区域 | 普通态 | 编辑态/特殊态 |
|:---|:---|:---|
| 主网格 | 点击启动，方向键选择，回车激活 | 编辑时不启动；翻页动画中不点击未到位 App |
| 搜索栏 | 单 icon、输入、清空、更多 | 展开组时不可编辑；输入法组合期间保留原生输入 |
| 页点 | 点击到页、当前页高亮 | 搜索/展开组隐藏；拖拽不能由普通翻页干扰 |
| 文件夹 | 点击/回车展开，名称可编辑 | 进入拖拽后接收空位/间距/内边距，仍有真实边界 |
| 编辑完成 | 右上“完成” | 退出抖动与叉号，不改变应用排序 |
| 管理菜单 | 刷新、隐藏恢复、设置、退出；系统菜单提供 LaunchOS 导入 | 文本、确认框与系统设置获得各自焦点 |

组内大容量导航和新页容量规则见 functional-overview.md 的 D2/D4，不以现有截屏视为已确定目标。单成员组按 FOLDER-08 自动解散。设置对组内图标与名称的作用范围也应明确后再改变现有布局。
