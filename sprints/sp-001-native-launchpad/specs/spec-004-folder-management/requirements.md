# spec-004：文件夹管理

## 产品依据与架构落地边界

- 细功能：FOLDER-01～10，逐项定义见 [功能清单](../../docs/functional-overview.md)；业务规则见 [SPRINT-features](../../docs/SPRINT-features.md)。
- 架构基线：[模块职责](../../../../architecture/architecture.md)、[数据模型](../../../../architecture/data-model.md)、[运行与偏好](../../../../architecture/runtime.md)。
- 进入状态：已有单层文件夹、系统玻璃面板、名称编辑、组内原生网格与开合；大容量导航形式待决定；单成员自动解散已明确为目标，当前路径仍不一致。
- 本规格实现程度：存量能力重组为功能板块规格，差距在 tasks.md 逐项列出；临时合组、单成员收尾及命名按本规格实现，具体验证边界见 check.md。
- 退出目标：可创建并命名、打开/浏览/关闭单层组，全部成员可访问，开合命中正确，空组/单成员规则在各入口一致。

## Context Contract

- 依赖 spec-001 的 LaunchGroup/有序成员、renameFolder、dropGroup、removeFromFolder。
- 依赖 spec-002/003 的窗口、选中与打开/关闭回调、实际图标几何。
- 向 spec-005 提供当前 folderID、展开面板几何与开合回调；本规格不复制拖拽事务。

## 局部设计与复原约束

### 结构和创建

LayoutStore.dropGroup 将一个单 App 普通组加入已有组，或与目标 App 建新组，顺序为目标 App 然后移入 App；默认名按标识关键词给游戏/开发工具/娱乐，其他为未命名。拖动触发时机归 spec-005，不另造一套建组手势。禁止嵌套文件夹的业务边界需包含单成员组对照，不能只依赖 apps.count==1 的判断。

### 呈现和生命周期

RootView 记录源图标矩形；FolderMorphSurface 对一次布局的 NSGlassEffectView/NSHostingView 做 Core Animation 缩放/位移/透明度，不逐帧调整网格。层 anchorPoint 参与 collapsedTransform。过渡或未展开时阻止内部命中，开合代次防止过时 completion 删除新面板。

FolderOverlay 上方是可编辑名称，下方是组内网格；外部 VisualEffectView 采用 within-window 模糊。尺寸和44连续圆角以 prototypes.md 为准；组缩略图/加入命中以 GridMetrics 为准，选中放大不扩大命中。

### 内容、命名和收尾

组内合成组以 App ID 为身份，仅作展示映射。当前7列，超高内容通过原生滚动容器访问，不存在独立横向组内页模型；D2 若选择原版分页需在本规格补方案而非新建“分页bug”规格。

renameFolder 对空白名回退“未命名”；FolderOverlay 将完全空/纯空白输入还原为当前默认名称。拖拽、菜单移出和卸载统一为成员减少到一个自动解散，零成员移除；预览期通过原快照支持撤销，不靠保留可见空壳。同容器内部重排不能在中间移除步骤误触发解散。

### 与拖拽的接缝

容器收尾：受影响组的最终成员数为0则删除，为1则在同一页同一位置转换为普通组，保留剩余App身份；普通组身份应稳定，不因每帧整理重新生成。临时组合撤销由005恢复其创建检查点，不对其他组做无关归一化；同组重排在完整操作末尾检查，不能中途解散。取消靠快照恢复原组。菜单移出/卸载复用相同收尾，不在本规格增加文件删除权限。

新组命名：005只在成功提交仍存在的临时组时发出一次命名请求。RootView与FolderOverlay接入该请求，保持组展开，在原生拖拽结束并可输入后聚焦名称、选中默认文本。用sessionID、folderID和请求代次过滤晚到请求；普通打开/加入已有组不触发。回车或失焦保存，空白回退默认名，Esc退出编辑不撤销已提交组。输入法marked text沿用原生行为。

NativeFolderMorphView 提供实际面板原生接收和弱引用登记；接收会话判断、转交、最终 drop 属 spec-005。保留正常点击和组内起拖，不以修复接收为由替换整套玻璃或动画。

## 临时边界与收口

没有新增Mock、后台服务或临时工具。存量实现保留；未实现/未决部分由本规格负责补齐，具体局部方案经评审后才能编码。用户已确认7个板块的拆分，不等于全部缺口技术方案已批准。不会用新bug规格绕开本板块维护。
