# spec-003：浏览、分页、搜索与启动

## 产品依据与架构落地边界

- 细功能：FIND-01～15，逐项定义见 [功能清单](../../docs/functional-overview.md)；业务规则见 [SPRINT-features](../../docs/SPRINT-features.md)。
- 架构基线：[模块职责](../../../../architecture/architecture.md)、[数据模型](../../../../architecture/data-model.md)、[运行与偏好](../../../../architecture/runtime.md)。
- 进入状态：已有 RootView、NativeLaunchGrid、PagingSurface、NSSearchField 与异步搜索索引；不意味着长列表、快速过渡或全输入组合已验收。
- 实现边界：存量与新增切片在同一功能板块维护；执行、差距与验收证据见tasks/check，不由接口存在推断全部能力完成。
- 退出目标：鼠标/键盘/触控板可找到并打开应用，分页不中断空间连续性，搜索不改变排序，空结果/错误/文本输入都有明确行为。

## 局部设计与复原约束

### 网格和分页

RootView 主页以 7×5 GridMetrics 展示；NativeLaunchGrid 使用 NSCollectionView，普通点击由实际 activation 区域决定，组点击使用圆角图标命中。分页以 NativePagingView 的单一裁剪面承载全部屏宽页面；网格留白随页移动，动画中拦截内部点击。

AppDelegate 对触控板锁定一次手势轴向，忽略惯性重新开页；非精确滚轮 220ms 节流。PagingSurface 使用位移加速度预测（0.15s、页面宽13%阈值），首页末页阻尼；代次隔离动画反向与隐藏。这些是现有复原参数，不是新的帧率保证。页点/Command-方向键走同一有界页号路径。

### 搜索和键盘

打开准备通知launchpadWillPresent携带NSNumber目标页：NativePagingView在窗口展示前停止动画、清除分页手势、clamp目标页、无动画设置host位置，并同步页码绑定；该路径不能调用普通翻页动画。RootView在同一准备阶段清空搜索/组状态。普通页点/键盘/触控板翻页规则不变。

ApplicationSearchEntry 对名称大小写/音调归一化，生成无空格拉丁转写和首字母。score：名称全等0、前缀1、包含2、拼音包含/首字母前缀3、Bundle ID包含4。RootView 在应用列表变化时后台生成索引，忽略已取消结果；只索引非隐藏 App。

NativeSearchField 使用 NSSearchField，移除其内置搜索按钮，由外部一个 SF Symbol 呈现。清空恢复主页；有结果默认索引0；搜索结果复用网格但 allowsReordering=false。方向键当前按7列导航；编辑文字时左右留给光标，marked text 留给输入法。大量结果可滚动，但未完整实机验收。

### 启动和输入互斥

RootView.openApp 调 store.open 后隐藏启动台；路径按 Bundle ID 回退，NSWorkspace 失败写 lastError。当前失败时启动台可能已关闭，错误待再次显示，这与立即可感知反馈有差距。右键打开直接调用 store.open，需和主路径一致核对。

主页普通翻页只在无搜索、无展开组、无拖拽时允许；组内与文本框不共享方向键解释。隐藏过滤当前存在组内成员与顶层处理差异，任务中显式保留，不以有 hidden 字段断言全局一致。

### 缓存与首屏准备（FIND-15）

资源缓存是可再生派生数据，不能保存或恢复布局。沿用001的 MainActor 布局唯一来源；以已有有效布局先显示，扫描后台执行后合并当前布局。扫描与拖拽隔离由001负责，003只消费应用列表。窗口生命周期由002提供，007接入壁纸与设置并负责整体体验验收。

ApplicationIconCache 保留同步内存命中入口，未命中时去重排队；新增 VisualResourceCache.swift 承担串行或有限并发后台磁盘读取、解码和写入。返回已经按目标像素尺寸解码的不可变位图，再在主线程更新对应图标。必须核对 NSWorkspace/NSImage 使用的线程约束；不能把含 AppKit 可变对象的整个操作直接 Task.detached，图像工作线程使用独立资源，不共享可变 NSImage。

两级缓存：解码位图内存预算64MiB、磁盘预算128MiB（实现初始上限，可经测量调整）。磁盘目录为用户 Caches/local.ilaunchpad.app/VisualResources/v1，按最近使用淘汰，仅管理该派生目录；原子写入、并发请求合并，失效/损坏/写满回退重建，不影响 App 启动和排序。图标键包含稳定身份、规范路径、应用版本/修改时间、资源指纹、目标像素尺寸、外观、系统与缓存格式版本。刷新动作取消旧代任务并失效缓存；迟到结果不能覆盖新资源。

壁纸同样缓存最终缩放/模糊位图，键包含来源URL及文件变化指纹、目标屏幕/像素规格和模糊档位；同路径替换也必须失效。Core Image工作复用后台上下文，最终赋值回主线程。解码失败保留现有背景或系统回退，不能使全屏空白。

首屏优先准备当前页所需图标及组缩略图，再处理邻页和剩余资源；取消/切页优先级按当前请求代次更新。移除 RootView 在主线程遍历所有图标的“预热”，Task.yield不等于后台解码。初次视图只创建当前页与相邻页的真实内容，其余保留完整页面几何占位；跳页先准备目的页，拖拽期间保活源页面和当前接收器，不能破坏跨组转交、跨页松手及全屏裁剪。所有过渡保持现有玻璃和视觉参数。
