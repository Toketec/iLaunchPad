# spec-001：验收清单

## AI 自检

- [x] 无自有或可导入布局时自动生成 Apple 默认风格布局，设置中可重新初始化。
- [x] 自定义备份最多 3 份，可新建、覆盖、重命名、删除和恢复。
- [x] 恢复前完整扫描，移除已卸载项、更新路径/名称并追加新应用，不反写原备份。
- [x] 普通刷新与备份恢复共用同一对账规则；已安装版本的真实扫描清除失效“贝锐向日葵”。
- [x] 拖拽预览中不切换；失败不改当前布局。
- [ ] 针对性测试通过。
- [x] release 构建与代码签名通过，已自动安装并启动 `/Applications/iLaunchPad.app`。

> 针对性测试文件已补齐，但当前 Swift 工具链缺少 `Testing` 模块，`swift test --filter LayoutBackupTests` 无法进入测试执行；不得把 release 编译当作单元测试通过。

## 人工验收

- [ ] 设置可直观区分 Apple 默认初始化与自定义备份恢复。
- [ ] 初始化、新建、覆盖、重命名、删除和恢复的原生交互清晰。
- [ ] 以真实已卸载“贝锐向日葵”和一个新安装应用验收对账结果。
- [ ] 切换后页面、文件夹、搜索与图标立即更新，不需要重启。

## 回归范围

- 现有布局保存、外部导入、文件夹收尾、拖拽取消、隐藏应用和新应用追加。
- 本规格不验收云同步、导出分享或无上限历史。
