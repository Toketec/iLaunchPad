# SPRINT-003：布局备份与切换

## 冲刺目标

让无任何可导入数据的 macOS 26、27 用户也能获得 Apple 默认风格启动台，并可安全保存、恢复最多三份自定义布局备份；恢复时不继续显示已卸载应用或漏掉新安装应用。

## 功能清单

| # | 功能 | 优先级 | 关联场景 |
|:-:|:----|:-----:|:--------|
| F1 | Apple 默认布局初始化与本地备份管理 | P0 | UC-01、UC-02、UC-06 |
| F2 | 切换时安装目录对账 | P0 | UC-03、UC-04、UC-05 |
| F3 | 设置中的即时切换反馈 | P1 | UC-02、UC-03 |

## 功能详述

### F1：本地布局配置管理

用户首次使用时，如果既没有自有 `layout.json`，也没有可用的 LaunchOS 导入，以当前已安装应用生成 Apple 默认风格布局。设置中也可二次确认后重新执行该初始化。用户可从当前排序保存最多三份自定义快照，可覆盖、重命名、恢复和删除；恢复后的继续整理不会自动改写原备份。

### F2：安装目录对账

每次手动刷新、应用目录变化或布局切换都使用同一对账规则：删除当前已不存在的应用，按 Bundle ID 更新已移动应用的名称和路径，将新应用追加到最靠近首页的未满页。删除成员后空组消失，单成员文件夹自动收尾；其余排序不变。

### F3：设置交互

设置窗口提供独立“布局”页。切换和对账期间禁止重复操作并显示原生进度反馈；成功后当前标记与启动台内容立即更新，失败则保留原布局并说明原因。

## 业务验收

- [ ] 无自有或可导入布局时，首次启动生成 Apple 默认风格布局，设置中可重新初始化。
- [ ] 可创建、覆盖、重命名并恢复 3 份自定义备份，第 4 份被明确拒绝。
- [ ] 切换到任意布局后，已卸载应用不出现，新安装应用不遗漏。
- [ ] 切换不打乱仍存在应用的顺序与文件夹名称。
- [ ] 失败或正在拖拽时不用半成品覆盖当前布局。

## 依赖与范围

- 依赖冲刺 1 的本机布局、应用扫描、文件夹收尾和设置窗口。
- 不引入网络、账户、云同步、历史时光机、导出包或自动定时快照。
- 不改动外部布局导入接受定义。
