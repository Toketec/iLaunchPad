# SPRINT-003：布局备份与切换 — 功能总览

## 核心功能

| ID | 功能 | 优先级 | 业务规则 |
|:--:|:----|:-----:|:---------|
| LAYOUT-01 | Apple 默认初始布局 | P0 | 无自有或可导入布局时自动生成；设置中可二次确认后重新初始化 |
| LAYOUT-02 | 自定义布局备份 | P0 | 用户可从当前排序保存最多 3 份快照，名称可编辑 |
| LAYOUT-03 | 备份管理 | P0 | 可创建、覆盖、重命名、恢复和删除自定义备份；后续整理不自动改写备份 |
| LAYOUT-04 | 安装状态对账 | P0 | 普通刷新与切换都删除已卸载项、更新已移动应用的名称/路径、追加新应用 |
| LAYOUT-05 | 稳定排序 | P0 | 存量应用保持原顺序；新应用追加到最靠近首页的有空位页 |
| LAYOUT-06 | 失败保护 | P0 | 扫描、解码或保存失败时保留当前可用布局并显示错误 |
| LAYOUT-07 | 即时界面更新 | P1 | 切换完成后网格、页数、文件夹和搜索使用新布局，不要求重启应用 |

## 用户故事

| ID | 用户故事 |
|:--:|:-----------|
| US-01 | 作为已整理好启动台的用户，我想保留当前布局，以便改动后仍能回到熟悉状态。 |
| US-02 | 作为没有旧 LaunchPad、LaunchOS 或 LaunchNext 布局的新系统用户，我想直接获得 Apple 默认风格排列。 |
| US-04 | 作为在不同场景使用 Mac 的用户，我想保存并恢复最多三份自定义布局。 |
| US-03 | 作为刚安装或卸载应用的用户，我希望切换布局后看到的是当前真实应用目录。 |

## 范围

本冲刺只做 Apple 默认风格初始化、单机布局备份、设置入口与应用目录对账。Apple 公开文档没有给出 macOS 26、27 逐图标顺序，因此模板依据历史 LaunchPad 的应用网格、文件夹和系统应用优先组织方式生成，不声称复制 Apple 未公开的固定清单。不做云同步、导出分享、定时快照、无上限历版本或跨用户共享。
