# Sprint 003：布局备份与切换 — UI 设计说明

## 设置页结构

在既有设置窗口增加“布局”标签，不改启动台主界面。

```text
┌─ 布局 ─────────────────────────────┐
│ Apple 默认布局                  恢复 │
│ 工作布局                          切换 │
│ 展示布局                          切换 │
│                                          │
│ [备份当前布局] 最多 3 份自定义备份 │
└──────────────────────────────────────────┘
```

- Apple 默认布局是初始化动作，不是当前布局的自动副本；执行前必须二次确认。
- 每份自定义备份提供切换、用当前布局覆盖、重命名和删除菜单。
- 切换时对应按钮显示系统进度指示并禁用所有布局操作。
- 新建和重命名使用原生文本输入提示；删除使用原生确认框。

本次直接沿用已有原生设置窗口，不另造网页交互原型。
