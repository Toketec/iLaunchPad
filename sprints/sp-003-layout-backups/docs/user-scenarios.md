# SPRINT-003：布局备份与切换 — 用户场景

## 用户旅程

| 阶段 | 用户动作 | 系统响应 |
|:----|:--------|:--------|
| 初始化 | 无可用布局时首次启动，或在设置选择 Apple 默认布局 | 扫描当前应用，生成系统应用优先、实用工具成组的布局 |
| 保留 | 在设置中备份当前布局 | 复制当前排序，在本地原子保存为快照 |
| 选择 | 恢复一份自定义备份 | 禁用重复操作并扫描当前安装应用 |
| 对账 | 等待切换完成 | 清理已卸载项，追加新应用，保留其余排序 |
| 使用 | 返回启动台 | 立即显示新布局；后续整理只修改当前 `layout.json`，不自动覆盖备份 |

## 用例

| ID | 场景 | 预期结果 |
|:--:|:----|:--------|
| UC-01 | 新系统无布局来源 | 自动生成 Apple 默认风格布局，不出现空启动台 |
| UC-02 | 备份当前布局 | 当前排序被复制为可命名快照，最多 3 份 |
| UC-03 | 恢复备份 | 目标快照经安装状态对账后立即显示，快照本身不改 |
| UC-04 | 删除应用后切换 | 已卸载应用不再出现，空组移除，单成员文件夹收尾 |
| UC-05 | 安装应用后切换 | 新应用进入最靠近首页的有空位页 |
| UC-06 | 管理备份 | 自定义备份可重命名、用当前布局覆盖或删除；Apple 默认模板始终可用 |

## 边界

| 场景 | 期望表现 |
|:----|:--------|
| 已有 3 份自定义备份 | 禁止新建并说明上限 |
| 名称为空或重复 | 不接受空名；重复名自动增加可辨识序号 |
| 正在拖拽 | 拒绝切换，不中断当前拖拽事务 |
| 扫描失败 | 保留当前布局和激活标记，显示错误 |
