# 冲刺 2：细功能清单

本文件是冲刺 2 细功能编号和归属的唯一入口。业务规则见 [SPRINT-features.md](SPRINT-features.md)，实现与验收状态只在所属规格的 tasks/check 维护。

| 板块 | 功能编号 | 唯一负责规格 |
|:---|:---|:---|
| 应用图标设计实现 | ICON-01～08 | [spec-001](../specs/spec-001-app-icon-design/requirements.md) |
| 产品官网设计实现 | SITE-01～10 | [spec-002](../specs/spec-002-product-website/requirements.md) |

## 1. 应用图标设计实现

| ID | 细功能 | 输入 → 用户可见结果及边界 |
|:---|:---|:---|
| ICON-01 | 品牌方向 | 看到图标 → 识别扁平火箭与 iLaunchPad，不依赖第三方品牌元素 |
| ICON-02 | 轮廓与比例 | 任意发布尺寸 → 主体清楚、留白均衡、圆润雅致，不尖锐或过小 |
| ICON-03 | 四款主题 | 打开图标选择 → 四款同构主题：默认玻璃蓝、玻璃紫、玻璃黑亮底与玻璃白暗底 |
| ICON-04 | 原稿可追溯 | 维护者查看资源 → 能对应原稿、生成提示、稳定 ID 与中文名称 |
| ICON-05 | 连续圆角封装 | 构建发布资源 → 统一连续曲率、透明外缘和规范尺寸 |
| ICON-06 | 系统呈现 | 选择图标 → Dock/应用切换器即时更新；访达保持包默认图标 |
| ICON-07 | 选择与回退 | 重启、未知 ID 或资源缺失 → 保持选择或安全回退玻璃蓝，不影响布局 |
| ICON-08 | 原创与权利边界 | 分发素材 → 只包含项目自有品牌图，不把第三方图标重新授权 |

## 2. 产品官网设计实现

| ID | 细功能 | 输入 → 用户可见结果及边界 |
|:---|:---|:---|
| SITE-01 | 首屏定位 | 首次进入 → 不滚动即可知道它为 macOS 26、27 补回 LaunchPad、如何增强体验及获取状态 |
| SITE-02 | 价值叙事 | 向下浏览 → 按单列的外观、交互、功能顺序理解产品；三项重点详述，其他能力快速扫读 |
| SITE-03 | 真实体验素材 | 查看演示/案例 → 只看到当前版本真实截图或录屏；未拍摄时为标注完整的空白素材槽 |
| SITE-04 | 功能与边界 | 查看功能 → 能区分已经补回/增强的能力、开发预览边界和未来高级能力方向 |
| SITE-05 | 真实获取状态 | 点击获取入口 → 进入实际存在的 Release/源码页并看到开发预览边界，不出现死链或假下载 |
| SITE-06 | 语言与主题 | 切换语言/外观 → 主要内容同步切换；白色/暗色默认跟随系统并保存手动选择 |
| SITE-07 | 响应式与可访问性 | 桌面/移动/键盘/减少动态效果 → 单列阅读顺序、液态玻璃层级与空白素材标注可读、可操作、不横向溢出 |
| SITE-08 | 搜索发现 | 搜索产品或兼容迁移 → 元数据准确；第三方名称只用于兼容事实 |
| SITE-09 | 原创与独立声明 | 查看页面与页尾 → 不复制竞品素材，不暗示 Apple 或第三方背书 |
| SITE-10 | 源码与托管边界 | 维护官网 → 代码在 `apps/website/`，规格在本冲刺，发布状态不反推本地验收 |
