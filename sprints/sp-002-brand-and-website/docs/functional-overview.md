## 1. 应用图标设计实现

| ID | 细功能 | 输入 → 用户可见结果及边界 |
|:---|:---|:---|
| ICON-01 | 品牌方向 | 看到图标 → 识别扁平火箭与 iLaunchPad，不依赖第三方品牌元素 |
| ICON-02 | 轮廓与比例 | 任意发布尺寸 → 主体清楚、留白均衡、圆润雅致，不尖锐或过小 |
| ICON-03 | 四款主题 | 打开图标选择 → 四款同构主题：默认玻璃蓝、玻璃紫、玻璃黑亮底与玻璃白暗底 |
| ICON-04 | 原稿可追溯 | 维护者查看资源 → 能对应原稿、生成提示、稳定 ID 与中文名称 |
| ICON-05 | 连续圆角封装 | 构建发布资源 → 统一连续曲率、透明外缘和规范尺寸 |
| ICON-06 | 系统呈现 | 选择图标 → Dock/应用切换器即时更新；访达保持包默认图标 |
| ICON-07 | 选择与回退 | 重启、未知 ID 或资源缺失 → 保持选择或安全回退玻璃蓝，不影响布局 |
| ICON-08 | 原创与权利边界 | 分发素材 → 只包含项目自有品牌图，不把第三方图标重新授权 |
