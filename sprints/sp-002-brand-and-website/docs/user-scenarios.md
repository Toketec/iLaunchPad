# 冲刺 2：用户场景

## 用户旅程总览

用户在客户端设置中选择喜欢的原创图标，系统立即呈现并在下次启动恢复。

| ID | 角色与触发 | 期望结果 | 对应功能 |
|:---|:---|:---|:---|
| U01 | 用户打开“应用图标”设置 | 看见四款同构预览、名称和当前选择，选择后即时更新 | ICON-01～07 |
| U02 | 已保存图标资源缺失或 ID 未知 | 自动迁移并回退玻璃蓝，设置仍可用，布局不变 | ICON-07 |

## 异常与边界

- 图标选择失败不改动包内资源和用户布局；回退可恢复，错误不伪装为成功。
- 第三方名称和视觉资产不进入品牌主标题、图标或产品名称。
