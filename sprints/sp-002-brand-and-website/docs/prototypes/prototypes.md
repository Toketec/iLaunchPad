# 冲刺 2：界面与内容原型

## A. 客户端应用图标设置

- 入口：系统设置窗口中的“应用图标”区。
- 布局：四款图标以自适应网格展示；每项包含图标、中文名称和完整按钮命中区。
- 状态：当前项使用系统选中反馈与辅助功能值，不使用自造蓝色描边；键盘可遍历。
- 行为：点击后立即更新 Dock 与应用切换器；保存稳定 ID。未知 ID、素材加载失败回退玻璃蓝。
- 视觉：同一火箭构图、连续圆角底板、均衡留白；玻璃蓝为默认，另有玻璃紫、玻璃黑亮底、玻璃白暗底。玻璃紫作为光效基准，四款均使用淡玻璃底、非发光主体和无周边光晕的面内渐变。

## B. 产品官网

### 页面结构

1. 顶部不设置传统导航栏。品牌标识轻量悬浮于 Hero 左上角，深浅主题与语言作为右上角两个液态玻璃圆形工具；下载和内容入口直接属于首屏，不再额外占用一行菜单。
2. 首屏：桌面端采用左文案、右真实客户端截图的双栏布局；以“macOS 26、27 的原生感替代方案”为状态标签，主标题为“你喜欢的启动台现已回归”，副标题用单行明确 LaunchPad 已经回归，再用一行说明全屏网格、分页、文件夹、搜索、拖拽整理及液态玻璃增强。右侧实机画面使用更宽、更高的展示比例，与精简后的左侧文案保持视觉重量平衡。Hero 背景使用淡海蓝、紫色和微暖色渐变，主按钮进入真实 Release，次按钮下滑到功能；移动端恢复单栏。左上品牌标识提高视觉面积，但不使用传统导航条。
3. 过渡宣言：只保留一句“找回原来的空间记忆，获得属于今天的体验”，不再用四项小字反复解释价值。
4. 外观：不切换色块，延续当前白色/暗色基底；用一项宽幅文件夹实拍素材槽和“连续曲率/动态模糊/高刷适配”三个玻璃标签展示质感。
5. 交互：居中说明翻页、文件夹与整理动作的连续性，下方使用当前客户端实录和“首页—展开文件夹—收起—跨页—返回”流程；未录入的拖拽能力只作文字说明，不用其他动作冒充。
6. 核心亮点：使用六项液态玻璃卡片集中呈现 macOS 26/27 原生适配、原生液态玻璃、丝滑高刷交互、既有布局兼容、6.4 MB 轻量开源和全球化方向；每项使用同一线性 SVG 图标体系，不使用字符图标。
7. 完整功能：全屏网格、搜索启动、拖拽整理、文件夹管理、快捷唤起、应用自动刷新、编辑移除和默认首页以八项紧凑网格快速扫读。
8. 布局延续：一张液态玻璃大卡明确当前支持 LaunchOS 只读导入，旧系统原生 LaunchPad 数据导入仍在规划中。
9. 不在官网展示应用图标选择；它是偏好能力而非产品核心卖点。FAQ 只保留下载状态、本地隐私和布局导入三项；最终 CTA 合并免费开源、未来高级能力方向、下载和源码入口。

### 真实素材与状态

- 首屏演示：`assets/media/hero-demo.webm` 与 `assets/media/hero-demo.mp4`，1920×1248、60 fps、约 27.5 秒；完全基于分页、搜索、拖拽换位、文件夹开合与长按编辑五段真实系统录屏。每段按当前操作位置进行缓入缓出的定位缩放，段尾回到完整构图并以柔和转场衔接；不叠加文字、假光标或网页模拟界面。`assets/media/home.png` 作为静态回退封面；首页保留一个“其他”文件夹和一个空位，不出现私人应用信息，也不叠加版本、标签或说明组件。
- 外观截图：`assets/media/folder.png`，16:10，展示同一首页“其他”文件夹展开后的背景模糊、图标间距与标题。
- 交互实录：`assets/media/interaction.webm` 与 `assets/media/interaction.mp4`，1920×1248、60 fps、约 17.2 秒，从同一批真实录屏中集中展示拖拽换位、文件夹开合与长按编辑，并使用与 Hero 相同的定位缩放；不宣称素材未实际拍摄的交互。
- 中英文：切换后标题、按钮、FAQ 与状态同步，不混合残留语言。
- 字号：最大标题与最小辅助文字向中间收敛，保持文雅、清爽、容易浏览的层级，不以极端字号差制造冲击。
- 中英文排版：中文各级标题、按钮与标签统一降低字重；英文正文优先使用 SF Pro Text、标题使用 SF Pro Display，在更轻字重基础上进一步放松标题、正文、按钮和标签的字距与行距，避免粗重紧贴。
- 深浅外观：首次访问跟随系统，用户可手动切换并保存本地偏好；两套主题共用同一字号、圆角和玻璃层级。
- 移动端：导航折叠，首屏先文字后素材槽；素材槽保持比例与完整标注，无横向滚动。
- 减少动态效果：取消内容漂移与大幅出现动画，保留即时状态变化。
- 获取入口：Release 与源码链接都必须真实存在；页面明确标注当前为 Apple Silicon / macOS 26+ 开发预览和未公证边界。
- 事实边界：轻量体积按当前发布构建实测写为 6.4 MB；官网已支持中英双语，客户端没有本地化资源时只写“全球化持续扩展”，不宣称完整多语言客户端。

### 原创边界

可以学习优秀工具网站“先定义价值、再展示证据、最后给出获取”的理念，但不得逐段复刻竞品顺序、比例、动效、文案或媒体。LaunchOS 只在兼容迁移说明与搜索元数据中准确出现，不进入产品主标题、Logo 或主要 CTA。真实素材必须来自 iLaunchPad 当前发布版本；旧版截图、网页模拟和第三方案例都不能作为占位替代品。
