# spec-002：产品官网设计实现

## 架构落地边界

- 细功能：SITE-01～10；页面与状态见本冲刺[原型](../../docs/prototypes/prototypes.md)。
- 当前架构基线：[模块职责](../../../../architecture/architecture.md)与[运行架构](../../../../architecture/runtime.md)。
- 进入状态：存在一份可运行的静态网站工作区，但此前位于根目录、没有归属 Sprint/Spec，也没有与产品文档形成 SSOT。
- 本规格实现程度：将官网归入 `apps/website/`，冻结首屏定位、价值叙事、真实素材槽、真实获取状态、中英文、响应式、可访问性、SEO 与原创边界。
- 退出状态：官网能从本规格重建、检查和发布；本地工作区、线上部署和用户验收三种状态分别记录。

## Context from Dependencies

### spec-001（应用图标设计实现）→ 品牌素材契约
- 官网只消费已批准的 iLaunchPad 自有图标及稳定资源。
- ocean 是默认品牌方向，个性化区只展示海蓝、紫色、黑底、白底四款选择。
- 官网不得改写图标目录、ID 或客户端偏好。
- 未批准素材用结构占位代替，不从竞品补齐。

## 局部实现方案

官网为 HTML/CSS/JavaScript 静态站点。语义 HTML 提供核心内容；CSS 以白色/暗色中性变量、六级统一字号和单列产品叙事为基础，不设置传统顶部导航栏，品牌与主题/语言工具轻量悬浮于 Hero 两侧；按钮、标签、媒体外框、功能卡、流程节点、迁移卡、图标容器、FAQ 与下载区共用液态玻璃材质变量。JavaScript 只负责语言、深浅主题和渐进增强，不绘制或模拟启动台。

信息架构以“macOS 26、27 移除 LaunchPad 后的明确缺口”为开场，主体按外观、交互、核心亮点、完整功能单向展开。核心亮点集中呈现系统适配、液态玻璃、连续高刷交互、布局兼容、轻量开源和全球化方向；完整功能用统一线性 SVG 图标网格快速扫读。未来高级能力只在最终获取区表达方向，不拆出多组路线卡片，不伪装成现成功能。

首屏必须在一次视野内依次回答“为什么需要、产品做什么、为什么值得选择”，完成产品定义、价值、获取状态和视觉证明位置；Hero 允许使用仅在首屏淡出的低透明度品牌渐变。当前版本截图与录屏尚未拍摄时，使用可访问的空白素材槽，写明素材类型、比例、拍摄动作和版本要求。任何素材槽不得包含 HTML/CSS 绘制的应用网格、虚构应用案例、旧版客户端画面或第三方媒体。

GitHub 仓库与 v2.3.6 Release 已公开，主 CTA 进入真实 Release，源码 CTA 进入真实仓库；同时说明 Apple Silicon、macOS 26+、开发预览和未公证边界。SEO 标题与描述以 iLaunchPad 独立品牌为主，LaunchOS 与 LaunchNext 只在兼容布局迁移的正文/元数据事实中适度出现。

根仓库 `.github/workflows/pages.yml` 是唯一发布入口，直接把 `apps/website/dist/` 部署到 GitHub Pages。网站内部 README 只说明本地运行、发布入口与 SSOT 链接，不复制需求。官网目录不保留嵌套 Git、`.openai` 或工具专属规则；项目级需求、架构和验收以根目录 SpecRocket 文档为准。

## 接口与数据

无 API、账号、数据库或客户端通信。语言与深浅主题状态为浏览器本地偏好，不属于产品布局；站点不上传应用清单、图标选择或布局文件。

## 边界

- 本规格不创建安装包、不改变 GitHub Release 内容；网站发布与访问权限需单独记录。
- 不复制竞品页面结构细节、文案、媒体、评论、价格或品牌识别。
- 不用线上页面存在证明本地代码已验收，也不用本地修改声称已部署。
- 不新增分析、Cookie 追踪、账号、支付或远程配置。

## 验收条件

- 首屏明确 macOS 26、27 LaunchPad 缺口、产品补回与增强价值、开发预览/真实获取状态，并展示清楚标注的真实首屏素材槽。
- 页面不再包含网页模拟启动台或虚构案例；所有体验位置均为空白素材槽或当前版本真实截图/录屏。
- 中英文、深浅主题、移动导航、响应式、键盘访问、减少动态效果与减少透明度符合原型。
- 脚本失败时核心文字可读；不存在空下载、横向溢出和阻断焦点的弹层。
- SEO 内容准确、独立，第三方名称只用于兼容迁移事实。
- 当前构建体积、布局兼容与全球化描述均符合实际：v2.3.6 ZIP 实测为 4.6 MB；旧版 macOS LaunchPad、LaunchOS 与 LaunchNext 导出 JSON 均以只读方式导入；官网中英双语不等同于客户端已完整本地化。
- Release、源码、规格链接真实存在；网站源码、文档、Pages 工作流和发布边界可追溯，不再游离于 SpecRocket。
