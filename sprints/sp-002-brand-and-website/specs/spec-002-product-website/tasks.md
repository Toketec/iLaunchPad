## 当前事实

`apps/website/` 已完成官网框架与真实媒体接入：旧网页模拟启动台、虚构案例和图标选择展示已移除；首屏为左文案、右无字幕产品导览的双栏结构。Hero 使用 macOS 系统原生录屏串联分页、搜索、拖拽换位、文件夹开合与长按编辑，交互区使用拖拽、文件夹和编辑模式的短版实录；两支视频只做裁剪、轻微定位放大与柔和转场，不加入网页模拟画面、说明文字或假操作。原布局已保存到应用支持目录的备份中，当前客户端使用按 macOS 15/Sequoia 默认顺序校准的初始化布局；首页明确保留“其他”文件夹和一个空位。页面按外观、交互、六项核心亮点、八项完整功能单列展开，最大与最小字号向中间收敛，仅使用白色/暗色中性主题；功能卡使用统一原创线性 SVG 图标。轻量体积按当前发布构建实测为 6.4 MB，全球化明确为官网中英双语、客户端继续扩展。主入口指向真实 v2.3.2 Release 与仓库。嵌套 Git、`.openai` 和 Finder 元数据已移出项目，官网由主仓库 GitHub Pages 工作流发布至 `https://toketec.github.io/iLaunchPad/`。初始化布局按用户要求暂不恢复；用户视觉签收仍未完成。

## 跨 spec 依赖

依赖 spec-001 提供已批准品牌图标；若图标尚未签收，官网使用原创结构占位，不阻塞内容与交互实现。

## 回归范围

首屏定位、所有 CTA、真实素材槽、无模拟客户端画面、中文/英文、键盘焦点、移动端、减少动态效果、SEO、原创与独立声明、线上/本地版本边界。
