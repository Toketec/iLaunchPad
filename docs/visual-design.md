# 视觉设计边界

## 设计语言

以用户要求的现代 macOS 原生液态玻璃质感为目标，保持壁纸可感知的层次、克制的高光与柔和深浅变化；不把兼容 macOS 26 的部署下限当作视觉目标。输入、菜单、确认提示优先使用系统组件；不另造与系统冲突的皮肤。产品视觉必须形成自己的构图、比例、动效节奏和品牌识别，不以复制某一同类产品作为完成标准。

## 颜色、图形与文字

应用标识保持扁平火箭方向，以玻璃蓝为默认识别，并保留玻璃紫、玻璃黑亮底、玻璃白暗底三款同构主题。紫色款是全系列光效基准：四款均使用淡淡、低对比的玻璃底板，火箭只靠表面渐变塑形，不自发光，轮廓周围不得出现光晕、霓虹描边或火焰外溢。四款火箭比例与视觉重量保持一致；头部、侧翼末端和火焰收为柔和圆弧，避免锐角、武器感和过小主体。底板使用 macOS 连续曲率，整体现代、雅致、在小尺寸仍能辨识。具体命名、资源和系统呈现行为归冲刺 2 图标规格。

界面使用系统字体、白色主文字与降低透明度的次级文字；玻璃背景以原生暗色外观为基础。圆角强调连续曲率，避免机械直角拼接；保持图标与文字的对齐、留白和可读性。具体页面尺寸与布局归属冲刺原型文档。

## 动效与反馈

展开和收起应从当前位置平滑衔接，缩放、透明度和位移统一节奏。文件夹被选中时整体放大，避免附加蓝色外框；拖拽换位使用位置过渡而非蓝色插入线。翻页应横跨全屏，边缘具有阻尼。减少动态效果时缩短或降低运动幅度。

启用默认首页时，打开前直接定位首页，再执行与首次打开相同的spread缩放/淡入；不横向滑回首页，不显示上次页的中间帧。普通翻页仍保留横向过渡。

玻璃必须体现背景模糊、连续曲率及柔和边缘，不能仅用半透明色块代替。图标、名称与拖拽影像应有稳定层级，不随重排闪现第二份实体。静态外观、过渡中间帧和连续操作分别评审；具体结构与尺寸只在冲刺原型中定义。

缓存和高刷优化不得降低图标清晰度、取消液态玻璃或改动已确认的尺寸/间距与意图停留参数。资源异步到达时局部更新，不让整页闪白、重新播放开场动画或突然跳位。低频设置可保留 SwiftUI 系统控件，不以重写所有界面作为原生质感的条件。

布局备份使用设置窗口的原生列表、按钮、文本输入与系统确认框。每份布局仅显示名称、当前选中态和必要操作；默认布局与自定义布局共用同一层级，不额外引入强色卡片或新的视觉主题。切换期间用系统进度反馈并禁止重复操作，完成后启动台内容就地更新，不重放开场动画。

## 官网视觉原则

官网首屏必须用“缺失原因—找回 Launchpad—为何值得选择”的顺序直接说明 macOS 26、27 的产品缺口、现代化增强价值与当前获取状态，并为真实客户端首屏保留宽幅主视觉。后续按“外观—交互—功能”的单列节奏展开，每个区块只讲一个主题，不连续使用左右对照、反复价值宣言或规格化小字。三项核心能力详述，其他能力用短卡快速扫读，让访客不需来回对比就能完整看完。

网站只使用白色与暗色两套中性主题，默认跟随系统并允许手动切换；不再用多个强色背景分割内容。Hero 可使用低透明度海蓝、紫色与微暖色径向渐变烘托品牌，渐变只作为背景光感并在首屏底部自然淡出，不延伸成页面色块。字体使用系统字体并固定为元数据、辅助文字、正文、卡片标题、区块标题和首屏标题六级比例，同级文字不因区块改变尺寸。导航、按钮、标签、媒体外框、功能卡、流程节点、迁移卡、图标容器、FAQ 与下载区共用同一液态玻璃材质体系：背景模糊、低对比玻璃边缘、统一上方内高光、连续曲率与深浅主题降级。页面基底和普通文本保持纯净，不以玻璃效果取代内容层级。真实截图/录屏未补入前，素材槽保持低对比空白，只显示“待补真实素材”、推荐比例和拍摄主题，不绘制任何模拟客户端界面。支持减少动态效果与减少透明度；禁止堆叠无意义粒子、霓虹光、自动轮播或不可控视差。
