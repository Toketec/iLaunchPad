# 官网视频源素材

`website-source/` 保存官网产品演示视频的真实 macOS 系统录屏输入。为满足 GitHub 单文件限制并保持仓库可直接克隆，素材统一保留原始 3600×2338 分辨率、归一为 60 fps，并使用高质量 H.264 编码；无字幕、无模拟界面。

| 文件 | 原录屏 | 内容 |
|:----|:------|:----|
| `website-source/page-swipe.mp4` | `滑动.mov` | 页面横向滑动 |
| `website-source/search.mp4` | `搜索.mov` | 搜索与结果反馈 |
| `website-source/drag-reorder.mp4` | `拖动调换.mov` | 应用拖动与实时换位 |
| `website-source/folder-open-close.mp4` | `app组开合2.mov` | 文件夹展开与收起的重录版本 |
| `website-source/edit-jiggle.mp4` | `长按抖动.mov` | 长按进入编辑与抖动状态 |

官网成片位于 `apps/website/dist/assets/media/`；本目录只保存可重新剪辑的输入素材，不直接参与页面加载。
