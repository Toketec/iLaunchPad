# iLaunchPad 官网

原创单页产品官网，核心定位是“为 macOS 26、27 补回并增强 LaunchPad”，使用项目自有文案与视觉资产。`dist/` 是可直接部署的静态目录；无外部运行依赖。页面已经接入同一客户端版本的真实首页、文件夹截图和交互录屏；核心亮点与功能网格只描述当前代码和已明确标注的规划边界。

全局设计原则见 `../../docs/visual-design.md`；产品与实现规格见 `../../sprints/sp-002-brand-and-website/`。本目录只保存静态站点代码，不维护第二套需求、架构、AI 规则或验收记录。

GitHub Pages 由根仓库 `.github/workflows/pages.yml` 发布 `dist/`。网站目录不保留嵌套 Git、`.openai` 或其他工具专属托管身份；本地修改、GitHub 提交、Pages 部署和用户验收分别记录。

竞品仅用于研究用户关心的问题，不复制其文案、页面结构细节、截图、视频、评价、价格结构或品牌识别。官网不使用 HTML/CSS 模拟客户端，也不使用旧版画面或虚构应用案例代替真实素材。本地修改不会自动发布，线上页面也不代表本地规格已经验收。
